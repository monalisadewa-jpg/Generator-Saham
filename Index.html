Catatan penggunaan

Generator ini dapat digunakan sebagai alat hitung dan kerangka riset.

  1. Isi harga saham saat ini, jumlah lot yang ingin dibeli, rata-rata saham saat ini, dan jumlah lot yang dimiliki.
  2. Untuk dividen, gunakan total DPS per lembar untuk periode setahun.
  3. Cari kode emiten untuk membuka ringkasan profil yang tersedia.
  4. Verifikasi angka fundamental, kepemilikan, harga, dan DPS di laporan resmi.
Koneksi harga publik dari browser dapat gagal karena batasan CORS, jaringan, atau perubahan API. Aplikasi ini tidak mengklaim data live terverifikasi bila sumber tidak berhasil diakses. Untuk data fundamental, pemilik saham, dan dividen terstruktur yang benar-benar ter-update, hubungkan API data berlisensi atau backend yang mengambil data resmi.
EQUITYLAB ID · Alat bantu analisis, bukan rekomendasi beli/jual. Selalu periksa tanggal, periode laporan, dan sumber data.

Pasang EquityLab ID di iPhone

Safari di iPhone tidak menampilkan dialog pemasangan otomatis. Ikuti langkah berikut:

  1. Buka halaman EquityLab ID langsung di Safari, bukan pratinjau file atau browser dalam aplikasi lain.
  2. Ketuk tombol Bagikan (ikon kotak dengan panah ke atas) di Safari.
  3. Pilih Tambahkan ke Layar Utama.
  4. Ketuk Tambah. Ikon EquityLab ID akan muncul di layar utama.

Jika pilihan tersebut tidak terlihat, gulir menu Bagikan ke bawah atau buka halaman melalui Safari.
